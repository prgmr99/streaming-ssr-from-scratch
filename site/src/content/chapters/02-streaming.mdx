## 반환값을 바꾸면 된다

앞 절에서 `renderToString`이 Suspense를 지원할 수 없는 이유를 봤습니다. `string`을 반환하기 때문에 "아직 없음"을 표현할 수 없다는 이유때문이었습니다.

그러면 반환값이 다른 함수를 쓰면 됩니다.

```typescript
const { pipe, abort } = renderToPipeableStream(<App />, {
    onShellReady() { ... },
    onAllReady() { ... },
    onError(error) { ... },
});
```

문자열 대신 스트림을 조작하는 도구를 돌려주고, 콜백을 받습니다.
콜백이 핵심입니다. "언제 무엇을 해라"를 미리 등록해두는 것이니, **시간을 담을 자리가 생깁니다.**
`renderToString`에는 이 자리가 없었습니다.

|                          | 반환                     | 기다림을 표현할 수 있나 |
| ------------------------ | ------------------------ | ----------------------- |
| `renderToString`         | `string`                 | ❌                      |
| `renderToPipeableStream` | `{ pipe, abort }` + 콜백 | ✅                      |

**shell이라는 개념**

`onShellReady`의 shell은 **Suspense 바깥 영역**을 말합니다.

```typescript
<div id="root">
  <h1>Todo List</h1>                          {/* shell */}
  <Suspense fallback={<div>loading...</div>}>
    <TodoList />                              {/* shell 아님 */}
  </Suspense>
</div>
```

`<h1>`은 기다릴 것이 없으니 즉시 만들 수 있습니다. `TodoList`만 2초가 걸립니다.
`onShellReady`는 기다릴 필요 없는 부분이 다 준비된 시점에 불립니다. 이때 응답을 내보내기 시작하면, 사용자는 2초를 기다리지 않고, 화면을 볼 수 있습니다.
